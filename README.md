# Ananda Mohan Paul — Portfolio

A simple, responsive personal academic portfolio.

## Files
- `index.html` — portfolio content
- `style.css` — responsive styling
- `assets/Ananda_Mohan_Paul_CV.pdf` — CV download

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository named `paulmohon97.github.io`.
2. Upload the contents of this folder (keep the `assets` folder).
3. In the repository, open Settings → Pages.
4. Select Deploy from a branch, choose `main` and `/ (root)`, then Save.
5. Your site will appear at `https://paulmohon97.github.io/` after deployment.

## Before publishing
- Check the CV PDF and all external profile links.
- The hero uses a typographic initials placeholder instead of a portrait. Replace it with a professional photo if you want one.
- Review the wording of your research interests and publication details.
